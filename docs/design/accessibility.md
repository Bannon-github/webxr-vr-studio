# Accessibility (XR)

WebXR a11y is still evolving; studio minimums:

1. **Seated mode** — all content reachable without standing or large arm reach.
2. **Height / IPD / turn sensitivity** — user settings persisted.
3. **One-handed mode** — critical actions available from either hand or gaze+pinch/click.
4. **Captions / transcripts** for dialogue and essential audio cues.
5. **Color-blind safe** status colors; do not rely on color alone.
6. **Motion reduction** — map OS/browser reduced-motion preferences to Tier A locomotion and disable decorative camera shake.
7. **Readable UI** — scalable text; avoid essential info only in periphery.
8. **Fallback** — desktop/inline preview for support and authors without an HMD.
