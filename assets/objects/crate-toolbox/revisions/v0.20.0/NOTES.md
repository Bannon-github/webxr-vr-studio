# crate-toolbox v0.20.0

Shipping/perf-gate UPGRADE on the same `objectId`. Not a new layer. No GLB in this folder.

- Runtime (`examples/interactive-prop`): present-path **ambient-only fill** (HemisphereLight off + one `AmbientLight`) while an immersive XR session is presenting, complementary to v0.15’s pixel-ratio clamp, v0.16’s antialias/MSAA off, v0.17’s NoToneMapping, v0.18’s IBL/`scene.environment` off, and v0.19’s directional / punctual off. Desktop lookdev still uses `HemisphereLight` (0.55) plus `DirectionalLight` `sun` (intensity 0.9). After punctual lights are hidden and IBL is nulled, MeshStandardMaterials still evaluate hemisphere (`NUM_HEMI_LIGHTS`) — more TBDR work than a single ambient on Quest 3. Meta WebXR guidance: minimize lights.
- r170 still counts a *visible* HemisphereLight with intensity 0 toward `NUM_HEMI_LIGHTS`. Intensity 0 does **not** drop the hemi loop. Present-path policy therefore sets **`visible = false`** and writes intensity 0, then enables one reused `AmbientLight` at intensity **0.4** (color `0xf0e6d4`, lookdev hemi sky). 0.4 is a readable fill after IBL / sun / hemisphere are gated — not a desktop lookdev match. On `sessionstart` (after 90/72 + FFR 0.75 + v0.15 `setPixelRatio(1)` + v0.16 antialias verify + v0.17 NoToneMapping + v0.18 IBL off + v0.19 directional off) helpers in `present-ambient-fill.js` save hemisphere visible + intensity. On `sessionend` restore both and disable/detach the present-only ambient (do not leak lights across sessions; do not dispose the reused light). Session events only — not per-frame (v0.8 allocation scrub kept).
- L5 activity contract unchanged (`closed` → `unlatched` → `open`; tool / fastener / return).
- LOD draws and texture caps unchanged (14/8/2 + fastener 1; pref 512 / max 1024). v0.19 directional off, v0.18 IBL off, v0.17 NoToneMapping, v0.16 MSAA off, v0.15 pixel-ratio clamp, v0.14 LOD1 half `normalScale`, and v0.13 LOD2 no-`normalMap` stay as they were.
- Quest 3 frame time / FFR still **unmeasured**. Do not treat this pulse as a 90 Hz pass. Cheaper present-path hemi / fragment cost is the intended delta.
