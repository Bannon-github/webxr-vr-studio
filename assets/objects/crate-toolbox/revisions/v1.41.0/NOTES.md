- **Why not displacementScale / displacementBias:** both can be stored by `MaterialLoader` (`if (json.displacementScale !== undefined)` / `if (json.displacementBias !== undefined)`) even when `displacementMap` is absent, and `Material.setValues` still rejects them on a fresh MeshBasic. `refreshUniformsCommon` reads `material.displacementScale` and `material.displacementBias` only inside `if (material.displacementMap)`. After this pin that branch is not taken. `WebGLPrograms.js` does not read `displacementScale` or `displacementBias`. `ShaderLib.basic` does not merge `UniformsLib.displacementmap`. Deleting them does not change the MeshBasic refresh path or the basic program, so they are a proven no-op for this pulse.
- **Why displacementMap can be own:** installed three@0.170.0 `MeshBasicMaterial.js` does not mention `displacementMap`. A fresh `MeshBasicMaterial` has `displacementMap === undefined` and `Object.hasOwn(material, 'displacementMap') === false`. `setValues` rejects `displacementMap`. `Material.copy` and `MeshBasicMaterial.copy` do not copy it. `Material.toJSON` writes `displacementMap`, `displacementScale`, and `displacementBias` when `displacementMap` is a texture. `MaterialLoader` then assigns `material.displacementMap = getTexture(json.displacementMap)`, `material.displacementScale = json.displacementScale`, and `material.displacementBias = json.displacementBias` with no type check, so the JSON round-trip leaves those as own keys on a new `MeshBasicMaterial`.
- **Why the absence:** while `isMeshBasicMaterial` is true, `refreshMaterialUniforms` calls `refreshUniformsCommon`. `if (material.displacementMap)` copies `material.displacementMap` into `uniforms.displacementMap` and writes `uniforms.displacementScale` / `uniforms.displacementBias`. `ShaderLib.basic` does not merge `UniformsLib.displacementmap` (lambert and later shaders, plus depth and normal, do), so `uniforms.displacementMap` is absent on the basic shader. `WebGLPrograms.getParameters` sets `HAS_DISPLACEMENTMAP` from `!!material.displacementMap`, `displacementMap` from `SUPPORTS_VERTEX_TEXTURES && HAS_DISPLACEMENTMAP`, and `displacementMapUv` from that map; `displacementMapUv` enters the program cache key. `WebGLProgram` emits `#define USE_DISPLACEMENTMAP` when that parameter is true. shaderID for `MeshBasicMaterial` stays `'basic'`. A leftover own `displacementMap` is not the r170 MeshBasic constructor shape and changes the basic program. `delete material.displacementMap` restores the absence. This pulse does not delete `displacementScale`, `displacementBias`, or `emissiveMap`. `emissiveMap` is the next `refreshUniformsCommon` read after `displacementMap`.
