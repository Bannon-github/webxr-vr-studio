# crate-toolbox v0.22.0

Shipping/perf-gate UPGRADE on the same `objectId`. Not a new layer. No GLB in this folder.

- Runtime (`examples/interactive-prop`): present-path **XR framebuffer scale factor clamp to 1** while an immersive XR session is presenting, complementary to v0.15’s pixel-ratio clamp, v0.16’s antialias/MSAA off, v0.17’s NoToneMapping, v0.18’s IBL/`scene.environment` off, v0.19’s directional / punctual off, v0.20’s ambient-only fill, and v0.21’s texture anisotropy clamp. `renderer.setPixelRatio(1)` and `renderer.xr.setFramebufferScaleFactor` are different knobs. Three r170 `WebXRManager` framebuffer scale is the XR eye-buffer resolution relative to the runtime’s recommended size. Default is often 1, but lookdev or future HUD code can raise it (sharper text) and blow Quest 3 fill. Studio policy: clamp to **1**; raising above 1 is stretch-only and must be measured on-device. Pair with existing FFR 0.75 + pixel-ratio 1.
- Three r170 API (verified): `setFramebufferScaleFactor(value)` exists; there is **no** `getFramebufferScaleFactor`. The private factor starts at `1.0`. `setSession` snapshots it into `XRWebGLLayer({ framebufferScaleFactor })` or a projection layer `scaleFactor`, then sets `isPresenting` and dispatches `sessionstart`. A set while presenting warns and does **not** rebuild the current layer (it only updates the private factor for the next session).
- Present-path policy: save the last-set / documented lookdev default (`DESKTOP_LOOKDEV_FRAMEBUFFER_SCALE` = 1), write `QUEST3_XR_FRAMEBUFFER_SCALE` (**1**). On `sessionstart` (after 90/72 + FFR 0.75 + v0.15 `setPixelRatio(1)` + v0.16 antialias verify + v0.17 NoToneMapping + v0.18 IBL off + v0.19 directional off + v0.20 ambient-only fill + v0.21 anisotropy clamp) helpers in `present-framebuffer-scale.js` apply the clamp. The example also sets 1 at renderer setup (before VRButton / `setSession`) so the *current* session inherits the clamp. On `sessionend` restore the saved lookdev/desktop scale first (reverse-safe; r170 has already cleared `isPresenting`). Session events only — not per-frame (v0.8 allocation scrub kept).
- L5 activity contract unchanged (`closed` → `unlatched` → `open`; tool / fastener / return).
- LOD draws and texture caps unchanged (14/8/2 + fastener 1; pref 512 / max 1024). v0.21 anisotropy clamp, v0.20 ambient-only fill, v0.19 directional off, v0.18 IBL off, v0.17 NoToneMapping, v0.16 MSAA off, v0.15 pixel-ratio clamp, v0.14 LOD1 half `normalScale`, and v0.13 LOD2 no-`normalMap` stay as they were.
- Quest 3 frame time / FFR still **unmeasured**. Do not treat this pulse as a 90 Hz pass. Cheaper / safer present-path eye-buffer fill vs accidental supersampling is the intended delta.
