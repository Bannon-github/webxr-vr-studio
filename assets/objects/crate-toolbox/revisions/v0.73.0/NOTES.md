Mesh-state fence, not a geometry pack change. Lid/latch/tool/fastener animation uses rotation/position on pivots / fastener mesh — this pin must not rewrite those xyz values or break L4/L5. Does **not** invent custom shaders, transparent materials, pin `mesh.visible`, change `matrixAutoUpdate`, or change `matrixWorldAutoUpdate` / `layers` / `up` / `scale` / `blendColor` / `blendAlpha` / dithering / A2C.
