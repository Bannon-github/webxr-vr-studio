# crate-toolbox v0.50.0

L3 packaging/perf UPGRADE on the same `objectId`. No GLB. Not a new layer.

- After v0.49 pinned `castShadow = false` / `receiveShadow = false` on packed color-only unlit MeshBasic visual **meshes** (and after opaque FrontSide / fog / toneMapped material pins / raycast disable / matrix freeze), **`pinColorOnlyUnlitBasicFrustumCulled` / `pinColorOnlyVisualFrustumCulled` set `mesh.frustumCulled = true` on packed color-only unlit MeshBasic visual meshes** (body LOD leaves + lid/latch/tool + fastener). Procedural create runs the helper after `pinColorOnlyVisualShadowFlags`. Packaged ingest pins after the same detect (does not hex-dedupe; does not invent materials/meshes). Does **not** merge meshes across `body` / `lidPivot` / `latchPivot` / `tool`, fold the fastener into an LOD batch (`fastener` / `fastenerMesh` stay outside `LOD_MERGE_SKIP_NAMES`), rewrite material type, invent a GLB, change matrix freeze, change raycast no-ops, change fog/toneMapped/opaque FrontSide/shadow pins, or change L4/L5 interaction. Named meshes `lidMesh` / `latchMesh` / `fastenerMesh` kept. The v0.37–v0.49 merge → weld → unused-attr strip → Uint16 compact → shared MeshBasic → Float16 → upload-release → matrix-freeze → raycast-disable → fog/toneMapped-pin → opaque-FrontSide-pin → shadow-flag-pin pipeline stays intact.
- **Verified r170 API (do not assume):** a fresh `Mesh` is already `frustumCulled === true` (`Object3D` default). This pulse still pins that flag true on color-only unlit stand-in **meshes** so packaged GLBs that set it false get corrected. A deliberately wrong color-only Mesh (`frustumCulled = false`) is corrected when it still passes `isColorOnlyUnlitBasic`.
- **Why:** Accidental DCC / packaged GLB `frustumCulled = false` forces WebGLRenderer to skip GPU frustum rejection and always draw that mesh on Quest 3. Unlit midtone stand-ins must not pay that. Mesh-state fence, not a geometry pack change. Does **not** disable culling, invert it, or invent a custom culling strategy.
- **Scope vs v0.49 shadow-flag pin:** v0.49 and v0.50 both hit the **13** packed color-only visual **meshes**. v0.49 pins shadow flags off; v0.50 pins `frustumCulled` on. Mapped / lit stay at authored / r170 Mesh defaults. Collider meshes stay untouched. Morph / interleaved skip the same pack-pipeline gate. Materials shared with a blocked collider / morph mesh skip the visual pin.
- **Gate (same as pack pipeline):** only color-only unlit MeshBasic. Skip `userData.collider` / `collider_*` names. Skip mapped / lit. Skip morph / interleaved geos (conservative). Skip materials shared with a blocked collider / morph mesh.
