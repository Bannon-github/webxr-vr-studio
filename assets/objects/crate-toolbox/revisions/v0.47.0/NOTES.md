# crate-toolbox v0.47.0

L3 packaging/perf UPGRADE on the same `objectId`. No GLB. Not a new layer.

- After v0.46 disabled visual `Mesh.raycast` (and after materials are the shared color-only unlit MeshBasics), **`pinColorOnlyUnlitBasicFlags` / `pinColorOnlyVisualMaterialFlags` set `material.fog = false` and `material.toneMapped = false` on packed color-only unlit MeshBasic materials**. Procedural create pins the three shared wood/brass/steel instances once at share time and again via the entity helper after raycast disable. Packaged ingest pins color-only MeshBasics after the same detect (does not hex-dedupe; does not invent materials). Does **not** merge meshes across `body` / `lidPivot` / `latchPivot` / `tool`, fold the fastener into an LOD batch (`fastener` / `fastenerMesh` stay outside `LOD_MERGE_SKIP_NAMES`), rewrite material type, invent a GLB, change matrix freeze, change raycast no-ops, or change L4/L5 interaction. Named meshes `lidMesh` / `latchMesh` / `fastenerMesh` kept. The v0.37–v0.46 merge → weld → unused-attr strip → Uint16 compact → shared MeshBasic → Float16 → upload-release → matrix-freeze → raycast-disable pipeline stays intact.
- **Verified r170 API (do not assume):** `new MeshBasicMaterial().fog === true` and `.toneMapped === true` (`Material` defaults; MeshBasic does not override them). This pulse pins those two flags false on color-only unlit stand-ins only.
- **Why:** Unlit midtones should not pay fog varyings/uniforms or lookdev ACES wash. Present path already uses `NoToneMapping` while immersive (v0.17); lookdev still uses ACES — `toneMapped = false` keeps authored midtones stable. `fog = false` drops fog from the MeshBasic program when `scene.fog` is set later. Material-state / shader-variant fence, not a geometry pack change.
- **Scope vs v0.46 raycast disable:** raycast hits all 13 visual MeshBasics. Flag pin hits the **3 unique** shared MeshBasic instances (wood / brass / steel). Mapped / lit stay at r170 defaults. Collider MeshBasics stay untouched. Morph / interleaved skip the same pack-pipeline gate.
- **Gate (same as pack pipeline):** only color-only unlit MeshBasic. Skip `userData.collider` / `collider_*` names. Skip mapped / lit. Skip morph / interleaved geos (conservative).
- **Measurement rule:** `userData.lod.stats.attrBytes` is the **pre-upload** CPU envelope (arrays still present at `attachToolboxLod`). After simulated / real GPU upload, live CPU attrBytes on those visuals → **0**; `BufferAttribute.count` (draws / tris / verts) stays. This pulse does not change that envelope.
