# crate-toolbox v0.38.0

L3 packaging/perf UPGRADE on the same `objectId`. No GLB. Not a new layer.

- After v0.37 merged same-material meshes on the **procedural** path, **packaged GLB ingest applies the same load-time helper** (`mergeSameMaterialMeshes` exported from `toolbox.js`) within each discovered `lod0` / `lod1` / `lod2` node. Direct mesh children that share a material **reference** concatenate (no weld). Multi-material meshes (`Array.isArray`) are skipped. Nested Groups / pivots inside a `lod*` node are not flattened. Merge does **not** cross LOD levels, colliders, or the fastener (`fastener` / `fastenerMesh`). Materials are not rewritten. Missing LOD names still fail soft (v0.36): no fake LODs, no merge attempt.
- **Unit/mock evidence** (not headset proof): a packaged `lod0` group with 3 `MeshBasic` children sharing one material becomes **1** mesh (3→1 draws; tris unchanged). Single-mesh groups are no-ops. Colliders and fastener stay untouched even when they share the material instance.
- Procedural path is **unchanged**: measured `userData.lod.stats` stay LOD0 **6** draws / 240 tris, LOD1 **4** / 96, LOD2 **2** / 24, fastener 1 draw. `drawCallsEstimate` stays **7**. Manifest `lod0Draws` / `lod1Draws` / `lod2Draws` remain those procedural counts — do not treat the mock 3→1 as a packaged hero measurement.
- Unique canvases stay **0**. Color-only unlit MeshBasic on LOD0 / LOD1 / LOD2. `setToolboxLod` is still visibility-only. Geometry, collider names, and L4/L5 activity are the v0.4.0–v0.37.0 set. Session present-path chain (v0.15–v0.22) and v0.8 allocation scrub stay as they were. The v0.38 `behavior.json` sidecar is frozen next to this manifest (`source.behavior`) so the revision resolves without reading a later current sidecar.
- **KTX2 / Basis** remains the packaging step when a DCC GLB lands. No GLB in this revision. Author still should batch same-material statics inside each `lod*` group in DCC; ingest now also merges when the GLB shares material instances.
- Quest 3 frame time / FFR still **unmeasured**. Do not treat this pulse as a 90 Hz pass. Fewer draws inside authored `lod*` groups (when GLB materials are shared) is the intended delta.
