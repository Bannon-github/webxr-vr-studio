# crate-toolbox v0.35.0

L3 packaging/perf UPGRADE on the same `objectId`. No GLB. Not a new layer.

- After v0.34 made LOD0 unlit `MeshBasicMaterial` with 256² albedo `map`s, **procedural LOD0 hero meshes drop the albedo `map`** and use color-only unlit `MeshBasicMaterial` (card-like) with wood / handle albedo midtone **`0x633318`** (`L3_LOD0_WOOD_COLOR` — same as `L3_LOD1_WOOD_COLOR` / `L3_LOD2_WOOD_COLOR`), brass albedo midtone **`0xBE7E31`** (`L3_LOD0_BRASS_COLOR` — same as `L3_LOD1_BRASS_COLOR`), and steel albedo midtone **`0xC1C3C9`** (`L3_LOD0_STEEL_COLOR` — 256² `steelAlbedo` pixel average ~192.53 / 194.53 / 200.53; formula midtone `t = 0.62 + brush×0.22 + n×0.1` at brush/n mid 0.5 is the same hex). No roughness/metalness uniforms — those do not apply to MeshBasic. `L2_TEXTURE_SIZE` stays **256**. `L3_LOD_ALBEDO_SIZE` stays **256** as the historical mid/far half-res constant (v0.26–v0.28).
- LOD1 stays v0.30 color-only unlit `MeshBasicMaterial` (wood albedo midtone **`0x633318`**, brass albedo midtone **`0xBE7E31`**, no map). Unchanged this pulse.
- LOD2 stays v0.29 color-only unlit `MeshBasicMaterial` at wood midtone `0x633318` (no map). Unchanged this pulse.
- Unique canvases **3 → 0** (stop allocating unused wood / brass / steel albedo canvases). Fastener is not an LOD mesh; it stays on shared LOD0 brass MeshBasic (now color-only brass midtone). `setToolboxLod` is still visibility-only (no per-switch material swap, no frame-loop allocation). Draws unchanged: 14 / 8 / 2 + fastener 1. Texture pref **256** / max 1024 remain historical authoring caps; all procedural LODs are color-only.
- Geometry, collider names, and L4/L5 activity are the v0.4.0–v0.34.0 set. Session present-path chain (v0.15–v0.22) and v0.8 allocation scrub stay as they were.
- **KTX2 / Basis** remains the packaging step when a DCC GLB lands (`docs/performance/ktx2-quest3-packaging.md`). Author LOD0 as **unlit/basic** (or `KHR_materials_unlit`) **without** a `baseColorTexture` (or a tiny 1×1 / vertex color) — the same Quest-far/mid pattern as v0.29/v0.30, now extended to hero LOD. Author LOD1 and LOD2 the same way. The runtime prefers a packaged GLB when present and does **not** rewrite materials at ingest. No GLB in this revision.
- Quest 3 frame time / FFR still **unmeasured**. Do not treat this pulse as a 90 Hz pass. Cheaper LOD0 fragments at arm’s length (no albedo texture sample / less texture bandwidth on Quest 3 TBDR) is the intended delta.
